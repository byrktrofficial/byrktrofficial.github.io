🛠️ Troubleshooting

The download will not start

Try refreshing the releases page and clicking the newest version again. Some browsers block downloads until you confirm that you trust the site. If you are on a work or school network, ask your administrator whether downloads are restricted.

Windows will not let me open the program

This is usually the standard security prompt described earlier. Click "More info" and then "Run anyway". If your computer is managed by an organization, its security settings may prevent new programs from running until they are approved.

Prices are not updating

Check that your computer is connected to the internet. If other websites load normally, close coinvault, open it again, and give it a few seconds to fetch fresh data.

My portfolio disappeared

Make sure you are opening the same copy of the program you used before. If the program was moved to a different folder, your saved data may still be in the original location.

Something looks wrong

The project is open source, and the issue tracker on the repository is the best place to report a problem. Describe what you saw and what you expected, and include the version number shown in the program.
